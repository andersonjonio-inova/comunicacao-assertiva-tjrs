# Encerramento do curso

Apresentação web responsiva com 32 registros fotográficos enviados por Anderson, mais o quadro final aprovado.

## Uso

- Setas, Page Up, Page Down, espaço e Backspace navegam.
- `P` inicia ou pausa a passagem automática.
- `F` ativa a tela cheia.
- Em celular, deslize lateralmente.
- O botão “Carregar trilha” permite selecionar, no próprio dispositivo, um arquivo de áudio autorizado. O áudio não é publicado no repositório.
